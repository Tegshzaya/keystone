# Keystone

A small, modular ERP system with inventory, orders and a double-entry ledger.

> Work in progress.

## Features

- Inventory tracking built on immutable stock movements
- Purchase and sales orders
- Double-entry ledger

## Tech stack

- C# / ASP.NET Core
- Go
- PostgreSQL
- Docker

## Getting started

```bash
git clone https://github.com/Tegshzaya/keystone.git
cd keystone
docker compose up
```
